# Muzon

Локальный музыкальный плеер для Linux. Tauri + Rust на бэкенде, React на фронте.

Собирал под себя, потому что надоели все существующие варианты — либо жрут память,
либо интерфейс из 2007-го, либо просто не то, что хотелось. Получилось примерно
то самое.

## Что умеет

- Библиотека с тегами, обложками, избранным и плейлистами
- Гэплесс и кроссфейд между треками, 10-полосный эквалайзер, тайм-стретч
- Синхронизированные тексты песен (LRC), редактор тайминга прямо в приложении
- Альбомы / исполнители / плейлисты отдельными вкладками
- Поиск по сайдбару + `Ctrl+K` командная палитра
- MPRIS (медиаклавиши, интеграция с DE)
- Таймер сна, хоткеи, темизация (в том числе цвета из темы рабочего стола)
- Зеркало фонотеки в S3-совместимом хранилище

## Облако (S3)

Настройки → «Облако (S3)». Подходит любое хранилище с API S3: AWS, MinIO,
Backblaze B2, Cloudflare R2, Yandex Object Storage. Кнопки-пресеты
подставляют адрес, регион и стиль адресации за вас.

Для Yandex Object Storage: адрес `https://storage.yandexcloud.net`, регион
`ru-central1`, ключи — статический ключ доступа сервисного аккаунта с ролью
`storage.editor`. Совместимость проверена запросом к самому хранилищу: оно
присылает в ответе свой каноничный запрос, и он совпадает с нашим побайтово
(тест `yandex_builds_the_same_canonical_request_as_we_do`).

| Поле | Что писать |
|---|---|
| Бакет | имя бакета |
| Папка в бакете | префикс, по умолчанию `muzon` |
| Адрес | пусто — AWS в указанном регионе; иначе `https://хост:порт` |
| Регион | `us-east-1`, если хранилище регионов не знает |
| Путь вида хост/бакет/ключ | для MinIO и своих серверов включено, для AWS снять |

Ключи доступа уходят в связку ключей системы (`secret-tool`, service `muzon`),
в файлах конфигурации они не хранятся.

Раскладка в бакете:

```text
<префикс>/tracks/<имя папки фонотеки>/<путь внутри неё>
<префикс>/library.json
```

Синхронизация двусторонняя и **никогда ничего не удаляет**: отправляется то,
чего нет в хранилище, скачивается то, чего нет локально. Файлы сравниваются по
размеру. `library.json` хранит избранное, счётчики прослушиваний и плейлисты и
не перезаписывается, а сливается: лайк остаётся лайком с любой машины, счётчик
берётся больший, плейлисты объединяются по имени.

Подпись запросов — SigV4 собственной реализацией (`data/s3/sigv4.rs`), сверена
с эталонным вектором AWS; сам клиент проверяется интеграционным тестом против
заглушки сервера (`tests/fake_s3.py`).

## Стек

Rust + [Tauri v2](https://tauri.app) + GStreamer на бэкенде, React + TypeScript +
Tailwind (shadcn/ui на Base UI) на фронте, SQLite для библиотеки.

## Запуск в разработке

Нужны: Node.js, Rust, GStreamer с плагинами (base/good/bad/ugly), webkit2gtk.

```bash
npm install
npm run tauri dev
```

## Сборка

```bash
npm run tauri build
```

Бинарник и бандлы окажутся в `src-tauri/target/release`.

# muzon-core

Общая Rust-библиотека без Tauri и Iced. Содержит единственную реализацию
GStreamer AudioPlayer, SQLite-библиотеку, сканер и теги, обложки, локальные
LRC, хранилища сессии и параметров воспроизведения. `src-tauri` переэкспортирует
перенесённые модули, сохраняя существующие пути импорта и файловые форматы.

`controller::Controller` используется нативным интерфейсом. Один рабочий
поток владеет плеером, очередью и сессией. Фронтенд отправляет команды,
читает последние Arc-снимки состояния и медиа; логика next/previous/shuffle/
repeat и восстановления использует `muzon-queue`. Сканирование и декодирование
медиа выполняются отдельными работниками. `shutdown()` останавливает плеер,
сохраняет последний playhead и дожидается работников; Drop также завершает
контроллер. При SIGKILL сохраняется только последняя периодическая сессия
(интервал сброса 60 секунд).

Пути БД, конфигурации и кэша передаются явно в CoreConfig. Ядро не обнаруживает
установленный профиль автоматически. Нативная оболочка дополнительно блокирует
свой профиль. MPRIS и сокет управления подключаются нативной оболочкой через клонируемый
ControllerClient. Клиент отправляет команды и читает снимки, но не владеет
завершением рабочего потока. barrier() подтверждает применение предыдущих команд;
его вызывают только из блокирующих работников. Трей, scrobble и S3 пока
принадлежат Tauri-оболочке. Существующая Tauri-политика очереди ещё работает во фронтенде:
общий контроллер используется только новым интерфейсом.

Обработчик GStreamer spectrum освобождается вместе с плеером, обе деки переводятся
в NULL. Переходы между одинаковыми URI нативный контроллер выполняет через EOS,
поскольку существующий движок сообщает gapless-переход сменой URI.

Плейлисты публикуются отдельным Arc-снимком имён и упорядоченных id треков.
PlaylistEdit сериализует создание, переименование, удаление, добавление,
исключение и перемещение трека. Ответ подтверждается после публикации состояния;
аудиоочередь при этом не меняется. База использует прежние таблицы и гарантирует
атомарность создания с содержимым и пакетного добавления. После сканирования
снимок перечитывается, учитывая каскадное удаление исчезнувших треков.

PlaybackEdit меняет отдельное поле настроек, сохраняя соседние параметры.
Предпросмотр применяется обеим декам, сохранение объединяется после 300 мс
без ввода и принудительно выполняется через save_audio()/shutdown(). Файл
настроек заменяется атомарно. Несохранённые скорости держатся по id трека и
записываются одной транзакцией; кэш не меняет Arc библиотеки во время
перетаскивания. Временный MPRIS Rate остаётся отдельной операцией.

```bash
cargo test --manifest-path crates/muzon-core/Cargo.toml
cargo fmt --manifest-path crates/muzon-core/Cargo.toml --check
cargo clippy --manifest-path crates/muzon-core/Cargo.toml --all-targets -- -D warnings
```

Тесты аудио используют fakesink и синтетические файлы, без звука и настоящей
фонотеки. Вспомогательные фикстуры доступны другим крейтам только с feature
`test-support`, которую Tauri включает в dev-dependencies.
